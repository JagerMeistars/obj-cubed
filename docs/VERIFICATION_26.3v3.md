# Experimental 26.3v3 — verification and scope

Prepared on 2026-10-31 for Minecraft 26.3. Plugin version: 0.10.0.
Published files are `objcubed.js` and `objcubed.zip`; the latter is the main
resource pack, including the integrated player-profile shaders. Model-specific
geometry, the shared profile catalog and the profile datapack are generated by
the plugin when exporting. They are not preconfigured demo content in the ZIP.

## Release checks

- 560/560 unit tests passed on the release source.
- JavaScript syntax and resource-pack validation passed: resource format 97.1,
  data format 121.0.
- 83/83 shader programs compiled to SPIR-V, translated by SPIRV-Cross and linked
  on NVIDIA OpenGL; 166 stages, zero failures. GPU: RTX 4060 Ti, driver 621.01.
- Packaging uses `tools/build-release.mjs`: deterministic ZIP entries, LF text,
  original binary bytes and a per-file SHA-256 manifest in `provenance.json`.
  The release contains shaders and the upstream license, without demo models.

These checks do not launch Minecraft and do not measure gameplay FPS.
Local evidence is retained under `audit/2026-10-31/release-26.3v3/` (not shipped).

## Related regression evidence, 2026-10-30

The rendering fixes included here were checked using the production shaders
in hidden OpenGL GPU tests, separately from Minecraft gameplay:

- 288/288 UV/alpha cases across six interpolation modes, item/entity/armor,
  single textures and atlases. Before the UV index fix, 160 cases failed.
- 276/276 animation timing/seam cases.
- 120/120 profile/ordinary fragment visibility cases across both windings,
  six alpha levels and five opaque/OIT phases. This isolates fragment survival,
  not full transparent composition or profile donor delivery.
- Batches up to 129 models, models with 4096 separate faces, and 14 instanced
  draws with up to 129 instances passed the respective comparison tolerances.
- Mirrored world/hand transforms and distinct negative Z magnitudes were
  reproduced and corrected. Export fixes need a fresh model export.

Native Blockbench OBJ-codec reproductions also confirmed the triangle-UV and
duplicate-texture-name fixes. The profile face subset is now validated in both
directions across animation frames: unsupported material switches are rejected
instead of exporting missing geometry.

## Remaining limits

- Player skins are experimental. Follow [the current setup guide](PLAYER_SKIN_TEST_EN.md).
  Different profiles in `item_display` context `none` need different exported
  slots; there are eight slots, not automatic per-player slot allocation.
- Dynamic player skins on worn armor are not implemented. This release does
  not include the separate historical Chroma or Photon adapters and does not
  claim their compatibility with the skin system.
- Zero or extremely small scales and general sheared transforms remain carrier
  limitations. Older carrier paths also retain GPU subgroup assumptions.
- No new live Minecraft, AMD/Intel, native Vulkan rendering or gameplay FPS
  validation was performed for this release. SPIR-V compilation alone does not
  establish correct native Vulkan rendering. Earlier live skin observations
  are identified as historical evidence in the skin guide.

## Reproduce basic checks

```text
npm ci
npm test
npm run test:pack
npm run build
```

The shader matrix additionally requires the matching vanilla 26.3 shader
includes and installed Java/LWJGL toolchain described in
[`tools/render-tester/README.md`](../tools/render-tester/README.md).
