### EN:
Update to objcubed for Minecraft 26.3. Blockbench plugin 0.11.0.

### Changes

- Play, pause or select a texture frame from a datapack, even when the model has no geometry animation. A texture can stay on one frame while the model keeps moving,
- Choose Flat, Smooth or Ambient for the whole model under Advanced. Ambient keeps world lighting without shading faces by direction,
- Fixed diagonal lighting seams on flat faces and harsh shading around small details and split edges on smooth models,
- Animation names can use up to 64 characters, including periods and hyphens. New datapack exports target the player by default,
- And a few other bug fixes...

Install both `objcubed.js` and `objcubed.zip`. Re-export models to use the new settings; for texture controls, reload both the model pack and the generated datapack. [Export guide](https://github.com/JagerMeistars/obj-cubed/blob/26.3v4/docs/GUIDE_EN.md) · [Player skins](https://github.com/JagerMeistars/obj-cubed/blob/26.3v4/docs/PLAYER_SKIN_TEST_EN.md).

### RU:
Обновление objcubed для Minecraft 26.3. Версия плагина Blockbench — 0.11.0.

### Изменения

- Анимацию текстуры можно запускать, останавливать и переключать через датапак, даже если у модели нет анимации геометрии. Текстуру можно оставить на одном кадре, пока модель движется,
- В разделе «Дополнительно» можно выбрать Flat, Smooth или Ambient для всей модели. В Ambient модель реагирует на свет мира без затенения по наклону граней,
- Исправлены диагональные перепады освещения на плоских гранях и резкие тени у мелких деталей и на стыках сглаженных поверхностей,
- В имени анимации теперь можно использовать до 64 символов, включая точки и дефисы. Для новых датапаков по умолчанию выбрана цель «Игрок»,
- И немного других баг-фиксов...

Установите оба файла: `objcubed.js` и `objcubed.zip`. Чтобы применить новые настройки, переэкспортируйте модели. Для управления текстурой обновите ресурсы через F3+T и перезагрузите датапак командой `/reload`. [Руководство по экспорту](https://github.com/JagerMeistars/obj-cubed/blob/26.3v4/docs/README_RU.md) · [Скины игроков](https://github.com/JagerMeistars/obj-cubed/blob/26.3v4/docs/PLAYER_SKIN_TEST_RU.md).
