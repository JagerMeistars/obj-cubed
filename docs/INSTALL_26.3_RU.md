# obj³ для Minecraft 26.3 — установка быстрого OpenGL-варианта

Быстрый вариант сохраняет исходный вершинный рендерер, анимацию и экипировку. Он исправляет обнаруженное смешивание вершин на AMD. Это экспериментальная сборка: нужны `GL_ARB_shader_ballot`, `GL_ARB_gpu_shader_int64` и `GL_ARB_shader_draw_parameters` в vertex shader. Intel ещё не проверен; Apple OpenGL не поддерживается. Для Vulkan этот пакет не подходит.

1. Установите `objcubed.js` через File → Plugins → Load Plugin from File в Blockbench.
2. Повторно экспортируйте модели и datapack для 26.3: нужны актуальные маркеры правой/левой руки и форматы пакетов 97.1/121.0.
3. Соберите обычный пакет моделей вместе с шейдерами из `objcubed/`. В каталоге проекта установите зависимости `npm ci`, затем подготовьте отдельную копию:

```sh
mkdir -p work
node tools/prepare-opengl-models.mjs my-resource-pack work/guarded-models
node tools/build-opengl-pack.mjs work/guarded-models work/fast-opengl
```

4. Скопируйте `work/fast-opengl` в `resourcepacks` и включите его в Minecraft 26.3 с выбранным рендерером **OpenGL**. Приоритет пакета должен быть выше других пакетов, заменяющих те же core shaders.

Подготовка добавляет по 16 невидимых служебных граней до и после геометрии предмета. Исходные позиции, UV, текстуры и кадры сохраняются; меняются их адреса в PNG. Пропуск этого шага может оставить дырки на границах между экземплярами моделей. Исходные файлы не изменяются, повторная подготовка уже преобразованного пакета запрещена.

Броня использует свои прежние текстуры экипировки. Новый шейдер восстанавливает углы из нескольких граней нативного куба; при недостатке точек применяется приближение по нормали и стандартным пропорциям humanoid.

Готовый тестовый пакет уже содержит подготовленные модели. Он не использует BVH-конвертацию. Не смешивайте его с прежним portable-пакетом: эти варианты заменяют одни и те же шейдеры, но требуют разных данных моделей.

[Проверки и ограничения](FAST_OPENGL_26.3.md). Эта ветка не объявляет новый стабильный GitHub Release.
