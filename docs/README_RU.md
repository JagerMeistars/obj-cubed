# obj³ (objcubed)

Плагин [Blockbench](https://www.blockbench.net/) для экспорта произвольных 3D-моделей в ресурс-паки Minecraft с помощью core-шейдеров. obj³ заменяет Python-скрипт и командную строку единым плагином Blockbench.

Автор плагина — **[JagerMeistars](https://github.com/JagerMeistars)**. Проект основан на **[objmc от Godlander](https://github.com/Godlander/objmc)** — оригинальном инструменте и шейдерах для кодирования OBJ-геометрии в текстуры и её отображения в vanilla Minecraft.

**Обновление для Minecraft 26.3 (плагин 0.9.4):** добавлены собранные шаблоны Blockbench для 16 типов экипировки. Исходные повороты и масштабы частей учитываются при экспорте: например, корпус волка больше не требует вручную снимать поворот −90°. Цветную модель можно редактировать в естественной позе; серые ориентиры исключены из экспорта. Инструкции, 50 доступных привязок (включая отдельные уши верблюдов и поводья с наездником) и ограничения описаны в [руководстве экипировки мобов и элитр](ANIMAL_EQUIPMENT_RU.md).

Старые конские модели без новых меток сохраняют прежнюю привязку к корпусу. Формат ресурс-пака — 97.1. Сохранены исправления свечения одноимённых элементов, сочетаний RGB, режима «Без тени», анимированных атласов с Flip UV и кадров современных текстур Blockbench. Автоповорот по умолчанию — **«Оба»**; сохранённые настройки остаются прежними. Повторный экспорт сохраняет старые и добавленные вручную строки `_give.txt` без дублей. В остановку анимации включена оптимизация [JustJabka из PR #13](https://github.com/JagerMeistars/obj-cubed/pull/13).

Замените плагин и ресурс-пак. Модели с затронутыми анимированными текстурами нужно переэкспортировать: исправляется содержимое PNG. При обновлении с 0.8.2 также переэкспортируйте модели со свечением. Уберите из выбранных пакетов прежний архив с названием `direct`, чтобы он не перекрывал новую сборку.

## Установка

1. В настольном Blockbench откройте **File → Plugins → Load Plugin from File** и выберите `objcubed.js`.
2. Поместите `objcubed.zip` в папку `resourcepacks` клиента Minecraft 26.3 и включите его выше пакетов, заменяющих те же core-шейдеры.
3. Создайте папку модели в `resourcepacks`, скопируйте в её корень `pack.mcmeta` из ZIP шейдеров и выберите эту папку для экспорта в плагине. Экспортёр добавляет `assets`, но сам не создаёт metadata ресурс-пака. Включите пакет модели вместе с пакетом шейдеров. Для рук и управления анимацией используйте свежий экспорт: 26.3 получает явные метки контекста предмета и актуальный формат datapack.
4. Перезагрузите ресурсы через **F3+T**. Для получения предмета используйте команду из созданного экспортёром файла `_give.txt`.

`objcubed.zip` — готовый ресурс-пак: положите его прямо в `resourcepacks`, без распаковки. Плагин устанавливается отдельным файлом `objcubed.js`. В ZIP находятся только файлы ресурс-пака; инструкции и контрольные суммы сборки доступны отдельно в репозитории и `dist`.

## Проверка и ограничения

Итоговая сборка 26.3 после объединения с `main`: **437 тестов**, **2856 GPU-сравнений** и **83 варианта шейдеров**. Состав файлов, контрольные суммы и границы проверки приведены в [описании релиза](RELEASE_26.3.md).

Для 0.9.4 прошли **433 автоматических теста**, включая воспроизведение двойного поворота волчьей брони, сохранение исходных осей и совместимость старого экспорта. Новые шаблоны дополнительно проверяются настоящим кодом парсера и OBJ-экспорта Blockbench без запуска интерфейса, а координаты сравниваются с нативной геометрией Minecraft. Подробности — в [отчёте шаблонов](TEMPLATE_VERIFICATION_2026-09-29.md). Это отдельная проверка геометрии; свежий игровой FPS для 0.9.4 не измерялся.

Для 0.9.0 прошли **412 автоматических тестов**, 200 проверок нативных поз и 1364 проверки анимации, атласов, привязок и повреждённых данных. Все 16 типов экипировки проверены в реальном Minecraft на OpenGL и Vulkan; сохранено 76 кадров. Измеренные погрешности GPU-сравнений и границы игровой проверки приведены в [отчёте 0.9.0](ANIMAL_EQUIPMENT_VERIFICATION_2026-09-29.md). Нового замера FPS при свободной видеокарте пока нет.

Следующие отчёты сохраняют результаты прежних версий, а не полный набор проверок новых привязок 0.9.0. Для версии 0.8.5 прошёл 341 автоматический тест. Текстурная анимация отдельно и в атласах была проверена в 736 GPU-сравнениях и 154 проверках времени: предметы, сущности, броня и GUI. Подробности метода — в [отчёте текстур и атласов](TEXTURE_ANIMATION_VERIFICATION_2026-09-29.md).

Декодер конской экипировки 0.8.5 проверен в 133 GPU-сценариях с настоящей геометрией Minecraft и ещё 288 сочетаниях атласов с анимацией геометрии и текстур. Исправлено попадание соседних пикселей на край анимированного атласа. Повторно прошли 1390 случаев color behavior (все 125 сочетаний режимов, включая «Без тени», кадры и масштаб; 5568 проверок). Все 2126 изображений прежних тестов цвета и текстур побайтово совпали с результатами до добавления конской экипировки. [Отчёт свечения и цвета](EMISSIVE_COLOR_VERIFICATION_2026-09-29.md) описывает соответствующие исправления, [проверка конской экипировки](HORSE_EQUIPMENT_VERIFICATION_2026-09-29.md) — функциональность 0.8.5 и границы той проверки.

В одном атласе анимируются до четырёх полос; при ширине 16px и 7–8 динамических контекстах отображения помещаются три. Экспортёр предупреждает о лишних полосах и оставляет их на первом кадре. Длительность кадра и плавный переход общие, число кадров у каждой полосы своё (до 255). В GUI текстура закреплена на кадре 0.

Настройки RGB относятся к моделям предметов. У надетой брони цвет красителя управляет анимацией; режимы тинта/оттенка к ней не применяются. В интерфейсе экспорта брони это указано отдельно.

Числа FPS исходного обновления от 28 сентября приведены в [игровом отчёте](LIVE_VERIFICATION_2026-09-28.md); [GPU-отчёт](GPU_VERIFICATION_2026-09-28.md) содержит исходные проверки геометрии и освещения. Игровые проверки 0.8.5 описаны отдельно в [отчёте конской экипировки](HORSE_EQUIPMENT_VERIFICATION_2026-09-29.md). Визуальная проверка интерфейса Blockbench не проводилась: счётчик кадров, видимость полей и сохранение настроек проверены программно.

Проверка API деформации и OBJ-кодека выполнена с плагином 0.8.1 и Blockbench 5.2.1; наличие API также подтверждено в установленной 5.1.6. Исправлены смешивание весов разных мешей и восстановление сцены после ошибки. Подробности и граница проверки интерфейса описаны в [отчёте Blockbench](BLOCKBENCH_COMPATIBILITY_2026-09-28.md).

Новый экспорт использует стандартный item atlas Minecraft 26.3. При экспорте в старую папку её atlas-файлы сохраняются: старый источник `item` в `assets/minecraft/atlases/blocks.json` может продолжать дублировать текстуры. Для проверки новой сборки используйте новую папку модели по инструкции выше.

Шейдеры передают данные между вершинными вызовами через subgroup-операции. Доступность операций и порядок выполнения зависят от видеокарты, драйвера и выбранного бэкенда Minecraft. Проверки OpenGL и Vulkan нужно проводить отдельно. Успешная компиляция для одного бэкенда не подтверждает работу другого.

Число граней и кадров по-прежнему влияет на объём данных и подачу геометрии. Броня использует несколько equipment-слоёв; каждый слой содержит полную текстуру данных модели. Нагрузка также зависит от числа одновременно видимых моделей, площади экрана, прозрачности и проходов OIT. Эта сборка не обещает конкретный FPS.

Контрольные модели для сопоставления с 26.2 находятся в `audit/2026-09-28/direct-benchmark-fixtures-final`: одинаковые входные OBJ и текстура экспортируются версиями плагина для 26.2 и 26.3. Пакеты моделей не содержат шейдеров; команды лежат в каждом `COMMANDS.txt`. Рядом есть нативные JSON-эталоны простого куба и модели из 2802 граней. Реальную сцену, положение камеры, настройки, порядок пакетов и бэкенд нужно сохранять одинаковыми.

## Воспроизведение сборки

Из корня репозитория:

```text
npm ci
npm test
npm run test:pack
npm run build
```

Результат записывается в `dist`. Сборщик только упаковывает `objcubed/` и плагин: бинарные PNG сохраняются побайтово, текст получает окончания строк LF. Порядок ZIP-записей и дата фиксированы, поэтому повторная сборка тем же Node.js/zlib из тех же файлов даёт тот же SHA-256.

Репозиторий проекта: https://github.com/JagerMeistars/obj-cubed. Предыдущий релиз для 26.2: `41bf938`, SHA-256 его ZIP: `81c458cf868bb8e974853c5460fdbec448f06c3e56da64768bd7c56e75e9537e`. Полные хеши файлов конкретной сборки находятся в `provenance.json`.

Обновление интерфейса 0.9.4: названия, подсказки и обучение переписаны на русском и английском. В блоке экипировки показаны доступные привязки; назначение групп, повтор деталей, ограничения и минимальная оценка слоёв перенесены под «?». Подсказки открываются при наведении и при переходе клавишей Tab. Исправлены описания FPS анимации, независимых настроек рук, возврата правок из редактора отображения и свечения всей модели.

Проверка этого обновления: 433 теста, разрешение переводов всех текстов и подсказок диалога, сохранение доступных привязок, открытие подсказки с клавиатуры, целостность HTML-шаблона и пакета. Интерфейс Blockbench и игровая сессия заново не запускались. Рендер и формат моделей не менялись; отчёты предыдущих GPU-проверок относятся к указанным в них версиям.
