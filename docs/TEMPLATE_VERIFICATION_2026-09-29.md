# Собранные шаблоны Blockbench — проверка objcubed 0.9.1

Дата: 29 сентября 2026. Проверка выполнена без Computer Use, запуска интерфейса Blockbench и новой игровой сессии.

## Что исправлено

Прежние шаблоны помещали локальные кубы всех привязок вокруг нуля. Они не показывали собранную нативную модель. При использовании собранной позы экспорт вычитал только Origin, поэтому нативный поворот части применялся повторно: типичный случай — корпус волка и поворот −90° по X.

Новые шаблоны показывают нативную исходную позу. Группы сохраняют исходные оси отдельно от редактируемого поворота. Экспортёр преобразует описатели несущих граней в эти оси; существующий шейдер затем восстанавливает правильную привязку. Учитывается нативный равномерный масштаб, в том числе 1.1 у лошади и 4 у счастливого гаста. Исходная геометрия предмета сохраняется, дополнительные повороты автора не отменяются.

Шейдеры не изменены, дополнительных операций или проходов GPU эта коррекция не добавляет. Число граней самой модели по-прежнему влияет на стоимость рендера; новый FPS не измерялся.

## Источник шаблонов

- Установленный Minecraft 26.3, реальные `LayerDefinitions`, `ModelPart` и `setupAnim`.
- SHA256 клиентского JAR: `4508d006323f24fa02876310c192d739af56516eb259000ac50f0909a68c9a2d`.
- 16 типов, 44 привязки, 202 нативные части, 213 элементов геометрии.
- Вершины граней используются вместо неполных bounds: учитываются inflate и зеркальные UV.
- 109 нативных частей объединены в 44 группы: 134 редактируемых куба; 79 неэкспортируемых элементов-ориентиров, включая 4 меша.
- Неподвижные относительно привязки накладки седла, уздечки, морды, гривы и уши входят в редактируемую модель. Независимо движущиеся неподдерживаемые части, скрытые детали и дополнительные повторяемые ноги/крылья остаются ориентирами.
- Сопоставление дополнительных частей проверяет постоянство относительной матрицы по четырём сохранённым состояниям. Оно не является доказательством всех возможных игровых анимаций.
- Встроенные цветные текстуры созданы для шаблонов; оригинальные текстуры Minecraft не вложены.

## Выполненные проверки

`npm test`: **426 / 426**, 30 файлов. Новые проверки сначала воспроизвели двойной поворот корпуса волка, затем проверили исправление, сохранение/загрузку осей, дополнительный поворот автора и прежний формат без новых метаданных.

`node tools/validate-equipment-templates.mjs` исполняет настоящий код Blockbench 5.2.1: разбор проекта, загрузку Outliner, обновление трансформаций, вычисление вершин кубов и OBJ-экспорт. Используется THREE r129; контейнеры данных и службы интерфейса подменены. Это проверка кода редактора без запуска самого приложения.

Для проверки экспорта используется цепочка настоящего плагина `getObjContents → buildOutput → encodeAnimalLayer`, затем независимое восстановление по алгоритму шейдера. Ожидаемые вершины получены из отдельного нативного probe Minecraft. Сравнены четыре сохранённых состояния каждого типа: `rest`, `moving`, `action1`, `action2`. Эти названия обозначают наборы полей состояния; у некоторых мобов часть наборов даёт одну и ту же позу.

Геометрический предпросмотр создаётся из трансформированных вершин загруженных `.bbmodel`, с учётом видимости частей. Он показывает собранную форму и экспортируемые группы. Это программная визуализация, а не скриншот Blockbench или Minecraft и не проверка текстурных материалов игры.

## Воспроизведение

1. `powershell -File tools/render-tester/run-native-equipment-probe.ps1 -OutputDirectory audit/template-native`
2. `node tools/render-tester/build-equipment-template-models.mjs`
3. `npm run build:templates`
4. `node tools/validate-equipment-templates.mjs --source <исходники-Blockbench-5.2.1> --three <three.module.mjs-r129> --probe audit/template-native/native-models.json`
5. `python tools/render-equipment-template-preview.py` (нужен Pillow).

Исходный fixture и генератор включены в репозиторий. Параметры пути валидатора позволяют использовать отдельную локальную копию исходников Blockbench. JSON с результатами текущего прогона расположен в `audit/template-native/template-proof/results.json`; хэши использованных исходников записаны в нём.

## Границы результата

Новые шаблоны требуют плагин 0.9.1. Старые проекты без исходных осей сохраняют прежние правила экспорта; произвольный импорт CEM автоматически не перенастраивается. Помеченные группы шаблонов должны оставаться на верхнем уровне. Серые повторяемые копии не обновляются при редактировании цветной детали. Полная проверка всех игровых поз и новый замер FPS для этой версии не проводились.

## Дополнение: поводья верблюдов, objcubed 0.9.2

Добавлена отдельная привязка `reins` для обычного верблюда и верблюда-кадавра. Она следует за головой и использует нативную часть `root/body/head/reins`, которую Minecraft скрывает без наездника. Уздечка сохраняет обычную привязку к голове. Нужны новый плагин и повторный экспорт; шейдер не изменён.

В редакторе условная группа показана постоянно. У носителя две активные грани: выбирается уникальная передняя плоскость, а не боковые плоскости с повторяющимися UV. Слои упаковываются по фактическому числу несущих граней; четыре неиспользуемых описателя заполнены нулями. Пустые грани плоских кубов шаблонов исключены из экспорта. Три плоских куба поводьев требуют трёх слоёв вместо девяти.

- Каталог: 16 типов, 46 привязок, 268 несущих граней. Шаблоны: 140 редактируемых кубов, 73 ориентира.
- `npm test`: 428 / 428, 30 файлов; проверена упаковка двухгранного носителя для обоих видов.
- Проверка настоящим кодом Blockbench: все 16 шаблонов, 5000 соответствий координат/UV и 12944 вершины после упаковки. Максимальная ошибка: 0.000002265 единицы Blockbench до упаковки и 0.0000200871 блока после неё; ошибка UV равна нулю.
- Для обоих видов проверены два скрытых состояния без наездника и шесть видимых состояний с наездником. Несущие UV не пересекаются с другими видимыми деталями: дополнительных копий нет.
- Скрытый OpenGL на RTX 4060 Ti: 208 / 208 сравнений нативных поз и 1488 / 1488 проверок анимации, атласов, Flip UV, свечения, Origin и повреждённых заголовков. Включены новые поводья, их многослойная упаковка и отсутствие пикселей без наездника.

Результаты: `audit/template-native/template-proof/results.json` и `audit/template-native/reins-animation/combined-summary.json`. Повторить GPU-проверку можно командами из `tools/render-tester/README.md`, задав новые каталоги вывода. Это проверка рендера в скрытом OpenGL-контексте, без ComputerUse; новая игровая сессия, Vulkan-подача и FPS не проверялись.

## Дополнение: отдельные уши верблюдов, objcubed 0.9.3

Для обычного верблюда и верблюда-кадавра добавлены `left_ear` и `right_ear`. Нативные уши имеют разные UV и независимые повороты относительно головы; в собранных шаблонах они теперь отдельные цветные экспортируемые группы. Привязка использует существующий формат v2, шейдеры не менялись.

Каталог: 16 типов, 50 привязок и 292 несущие грани. Шаблоны: 144 редактируемых куба и 69 ориентиров. Прежние проекты сохраняются; чтобы использовать новую геометрию, назначьте группы соответствующих ушей или откройте обновлённый шаблон и переэкспортируйте модель плагином 0.9.3.

Проверено: 430 / 430 тестов; все 16 шаблонов настоящим кодом Blockbench, 5000 соответствий координат/UV и 13328 вершин после упаковки по четырём нативным позам. Максимальные ошибки не выросли: 0.000002265 единицы Blockbench до упаковки, 0.0000200871 блока после неё, UV — 0. Для ушей и поводьев проверено отсутствие пересечений несущих UV с другими видимыми деталями.

Скрытый OpenGL на RTX 4060 Ti: 224 / 224 сравнения нативных поз и 1736 / 1736 проверок анимации, атласов, Flip UV, Origin, свечения и повреждённых заголовков. Включены оба уха обоих видов; анимационные проверки используют нативную позу с повёрнутыми ушами. Данные: `audit/template-native/ears-proof/results.json` и `audit/template-native/ears-animation/combined-summary.json`. Без ComputerUse и новой игровой сессии; игровой FPS и Vulkan-подача не проверялись.
