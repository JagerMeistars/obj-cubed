# Совместимость Blockbench — проверка 28 сентября 2026

Плагин **obj³ 0.8.1** предназначен для прямого порта рендера Minecraft Java
26.2 → 26.3. Установленный Blockbench имеет версию **5.1.6**; актуальный
официальный стабильный выпуск на дату проверки —
[5.2.1](https://github.com/JannisX11/blockbench/releases/tag/v5.2.1).
Наличие нужных API проверено в установленном `app.asar` 5.1.6 и официальном
исходном коде 5.2.1. Минимальная версия плагина осталась 4.8.0; это само по себе
не подтверждает проверку всех промежуточных версий.

## Исправления

- Экспорт анимации использует штатный
  [calculateVertexDeformation](https://github.com/JannisX11/blockbench/blob/e2ede0809ee6bc91f374ac7e00d34cffbdf86a14/js/outliner/types/armature.ts#L154)
  при наличии этого API. Его
  [getVertexWeight](https://github.com/JannisX11/blockbench/blob/e2ede0809ee6bc91f374ac7e00d34cffbdf86a14/js/outliner/types/armature_bone.ts#L86)
  учитывает принадлежность веса конкретному mesh. В резервном алгоритме также
  исправлена изоляция весов: совпадение имён вершин больше не передаёт чужую
  деформацию неподвижному mesh.
- При ошибке OBJ-экспорта сначала восстанавливаются исходные вершины и время
  таймлайна, затем вызывается preview. Это исключает повторную деформацию уже
  запечённых вершин при восстановлении сцены.
- Экспорт для 26.3 больше не добавляет весь каталог `item` в `blocks.json`:
  стандартный `items.json` уже собирает эти текстуры. Существующие пользовательские
  atlas-файлы сохраняются побайтово; старые дублирующие источники автоматически
  не удаляются.

Четыре исходных режима easing сохранены.

## Подтверждённые проверки

Полный набор unit-тестов: **249 проходят**. Регрессионные проверки ошибок весов,
восстановления состояния и atlas-экспорта сначала воспроизвели дефекты, затем
прошли после исправлений.

Отдельная проверка в Node исполнила официальные методы деформации 5.2.1,
THREE r129 из установленного приложения, фактический код плагина и
[официальный OBJ-кодек](https://github.com/JannisX11/blockbench/blob/e2ede0809ee6bc91f374ac7e00d34cffbdf86a14/js/formats/standards/obj.js).
Проверены **2 рига, 4 mesh, 3 кадра и 48 позиций вершин** с вращением и
перемещением. Максимальная абсолютная ошибка относительно независимо
рассчитанных координат — **4.44e-16**. Изоляция весов, восстановление исходных
вершин и таймлайна, а также preview после намеренной ошибки кодека проходят.

Отрицательный контроль с исходным плагином 26.2 (`41bf938`, только добавлен
тестовый доступ к функции экспорта) падает: координата неподвижной вершины
равна `−1` вместо ожидаемых `5`.

## Граница проверки

**Живого теста загрузки плагина и его интерфейса в Blockbench не было.**
Попытка запуска официальной переносимой 5.2.1 с изолированным профилем была
отклонена автоматической проверкой разрешений: `blocked by policy`. Более
конкретная причина не сообщалась; запуск не повторяли и запрет не обходили.
После этого пользователь запретил Computer Use. Установленный профиль и
плагины Blockbench не изменялись.

Проверка Node подтверждает работу API и экспорта в указанном сценарии,
но не загрузчик плагинов, диалоги или поведение настоящего интерфейса редактора.
Подробные логи, исходники тестового стенда и хеши проверенных источников
сохранены в рабочем аудите `audit/2026-09-28/` и могут не входить в ZIP.
